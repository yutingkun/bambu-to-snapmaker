# 拓竹转快造 · bambu-to-snapmaker

**v0.1 — 初步测试版（Experimental / Pre-release）**

用于 Codex 的技能：直接修改 3MF 内的 JSON/XML 配置，将拓竹 Bambu Studio 工程迁移到快造 Snapmaker Orca，尽可能保留模型、涂色和工艺意图。

## 功能

- 采用完整 Snapmaker 打印机与逐槽耗材预设。
- 迁移支撑、拼缝、层高、填充、顶面纹理。
- 同步工程配置、内嵌工艺、继承关系和工艺覆盖清单。
- 默认直接转换字段，不打开软件、不自动打印。

默认目标为 Snapmaker U1 0.4 mm，PLA 默认 Snapmaker PLA Basic @U1，拼缝默认背后对齐；均可按用户要求调整。

## 使用

将技能文件夹放入个人技能目录，确保目录直接包含 SKILL.md。

示例：使用 $bambu-to-snapmaker 迁移这个拓竹 3MF，尽可能保留工艺，并核对支撑和拼缝。

## 测试范围

这是 v0.1 初步测试版，仅依据少量样本和合成配置检查整理。静态检查不代表软件一定正确加载，也不代表已完成切片、碰撞检查或实机验证。不保证全部软件版本、机型、材料和多盘多工艺兼容。

历史反馈包括支撑覆盖项漏失，本版加入工艺覆盖清单和内嵌预设一致性检查，尚未独立确认全部实际加载路径。

本仓库提供技能指令和静态检查工具，不是任意工程的一键转换器。不分发用户模型、3MF、G-code 或完整厂商预设。
